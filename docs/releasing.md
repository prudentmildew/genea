# Releasing Genea

A release is an Apple Silicon `Genea.app`, signed with Developer ID and the
hardened runtime, notarized and stapled, inside a DMG that is itself signed,
notarized and stapled. It goes on the repo's GitHub Releases, where the
in-app update check finds it (spec #19, Packaging and updates; ticket #64).

```sh
scripts/release.sh            # the release (needs the credentials below)
scripts/release.sh --local    # a dry run: ad-hoc signed, not notarized
```

The output is `dist/Genea-<version>.dmg`. The script never publishes.

## What it targets

- **Apple Silicon only** (`aarch64-apple-darwin`); the script fails if the
  binary isn't arm64-only.
- **macOS 14 or later.** The pinned Slint/winit/wgpu stack supports older
  versions, so 14 is the floor. The script builds with
  `MACOSX_DEPLOYMENT_TARGET=14.0`, writes `LSMinimumSystemVersion` and fails
  if the binary's `minos` isn't 14.0 (a prebuilt static library for a newer
  macOS would raise it silently).
- **The hardened runtime with no entitlements.** Genea needs no JIT, no
  unsigned executable memory and no third-party dylibs. Child processes
  (Node, pnpm, Bun, tsgo) are separate executables with their own signatures.
- **Bundle identifier** `io.github.prudentmildew.genea` (`packaging/Info.plist`).
  It is permanent once a release ships.

## One-time setup

1. A **Developer ID Application** certificate in the login keychain (Apple
   Developer Program → Certificates). Check it with
   `security find-identity -v -p codesigning`.
2. A **notarytool keychain profile**, with an app-specific password or an App
   Store Connect API key:
   ```sh
   xcrun notarytool store-credentials genea-notary --apple-id <id> --team-id <TEAMID>
   ```
3. **cargo-about** 0.9.2, for the licence check:
   ```sh
   cargo install cargo-about --locked --features cli --version 0.9.2
   ```

## Making a release

1. Bump `version` in `[workspace.package]` in `Cargo.toml` (it is the app's
   version and what the update check compares against).
2. Run the benchmark harness (ticket #23); a missed Genea budget
   blocks the release.
3. Regenerate the third-party licences if dependencies changed, and commit:
   `scripts/third-party-licences.sh`.
4. Commit, then tag the commit `v<version>` (the update check reads the
   release's tag, so it must match `Cargo.toml`).
5. Build:
   ```sh
   GENEA_SIGNING_IDENTITY="Developer ID Application: <Name> (<TEAMID>)" \
   GENEA_NOTARY_PROFILE=genea-notary \
   scripts/release.sh
   ```
   It refuses a dirty tree, an untagged HEAD, a tag that doesn't match the
   version, a missing identity or a stale licence list. Then it builds,
   bundles, signs, notarizes and staples the app, builds the DMG, signs,
   notarizes and staples that, and finally asks Gatekeeper (`spctl`) about
   both, which is what a clean machine decides on.
6. **Check on a clean machine** (or a fresh macOS user account): download the
   DMG through a browser so it gets the quarantine flag, open it, drag Genea
   to Applications and open it. There must be no Gatekeeper warning.
7. Publish (manual):
   ```sh
   git push origin v<version>
   gh release create v<version> dist/Genea-<version>.dmg --verify-tag --title "Genea <version>" --notes-file <notes>
   ```
   Don't mark it as a pre-release or a draft: the update check only sees the
   latest full release.

## The update check

At most once a day, starting 10 s after launch and off the main thread, Genea
asks `https://api.github.com/repos/prudentmildew/genea/releases/latest`.
If its `tag_name` is a newer version than the running one, every window
shows "Genea <version> is available", linking to the release page. There is
no in-app installer. The time of the last check and what it found are kept in
`~/Library/Application Support/Genea/update-check.json`, so restarts don't
check more often. Failures are silent.

## Third-party licences

`packaging/third-party-licences.txt` is compiled into the app and shown in
Help › About Genea, under the AboutSlint badge that Slint's royalty-free
licence requires. It is generated by `scripts/third-party-licences.sh` from:

- every crate in `genea-view`'s graph on `aarch64-apple-darwin` (build and
  dev dependencies excluded), via cargo-about (`packaging/about.toml`,
  `packaging/licences/third-party.hbs`). MPL-2.0 crates (`nucleo-matcher`)
  get a source-code notice with their repository;
- Slint's royalty-free licence text (from `patches/i-slint-common/LICENSES`);
- what isn't a crate: the Inter font embedded by `i-slint-common`
  (`packaging/licences/Inter.txt`) and Skia (`packaging/licences/Skia.txt`,
  from skia-bindings' prebuilt binaries).

A new Slint crate needs a `[<crate>.clarify]` entry in `packaging/about.toml`.
A licence not yet in its `accepted` list makes generation fail, on purpose:
decide whether Genea may ship it, then add it.
